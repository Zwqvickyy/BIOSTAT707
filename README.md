# BIOSTAT707
## Checkpoint 1
I run pixi run --locked checkpoint1 from the BIOSTAT707 project folder. The checkpoint1.py file combines the Set A time-series data into set-a_long.csv. It then creates table1.csv for patient characteristics, such as their mean and sd, outcomes.csv for the outcome summary about patients percentage of death, and measurement_ranges.csv for checking the measurement ranges, and to check if there any ranges are rare or wrong. 
Next, it summarizes each patient’s measurements and saves the patient data in set-a_wide.csv. The missingness_map.png is a Proportion Missing per Variable plot showing the percentage of patients missing each measurement, and TroponinI miss the measurements most. The missingness_vs_death.csv compares the in-hospital death rate between patients with and without each measurement to check whether missingness may be related to the outcome.
